# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Graduation project: an AI-assisted medication tracking and family notification system for elderly users, built with React Native (Expo SDK 58, TypeScript), Supabase, and Expo Notifications. `README.md` is written in Turkish and lists the planned features.

Sprint 1 (issues #1–#4) is implemented; see `docs/sprint1-plan.md` for its decisions and risks. Data lives on the device in AsyncStorage. Supabase is not connected yet and `supabase/` is empty.

## Commands

The repo has no root `package.json`, so run all of these from `app/`:

```bash
npx expo start              # dev server (i / a / w to open iOS, Android, web)
npx tsc --noEmit            # typecheck
npx expo install <package>  # add dependencies with SDK-compatible versions
npx expo-doctor             # diagnose dependency and config issues
```

- `expo-env.d.ts` is gitignored and generated by `expo start`. On a fresh clone, `tsc` reports missing CSS module types until the dev server has run once.
- No test runner is set up.
- ESLint is not installed yet. The first `npx expo lint` adds it and its config to the project, so expect `package.json` changes.
- `tsc` also needs the typed routes that `expo start` generates, so restart the dev server once after adding a route.
- Notifications, the camera, and haptics can only be verified on a real phone.

`app/AGENTS.md` holds the Expo rules: check versioned docs rather than relying on memory, and never hand-edit generated `ios/` or `android/` folders.

## Architecture

- **Routing:** Expo Router with its root at `app/src/app/` (not `app/app/`), using a single `Stack`: `index` (today's doses), `ilac-ekle` (add medication), `aldim/[id]` (full-screen confirmation, with `time` and `date` params). Typed routes and the React Compiler are enabled in `app.json`.
- **State:** `src/context/medications.tsx` loads everything once from `src/lib/storage.ts` and owns all writes. It holds splash-screen readiness through `isLoaded`, so the root layout must keep rendering the `Stack` while loading.
- **Dose status is derived, not stored:** only taken doses are saved as `DoseLog`. `getTodayDoses` in `src/lib/doses.ts` computes pending and missed from the clock (missed after 30 minutes). `DoseLog.id` is deterministic, which prevents a dose from being confirmed, or stock from dropping, twice.
- **Notifications:** `src/lib/notifications.ts` schedules local daily notifications with the ID `${medicationId}-${time}`. `syncNotifications` reconciles them with stored data on launch and leaves `test-*` IDs alone. The root layout turns taps into navigation through `useLastNotificationResponse`, including from a closed app.
- **Platform differences:** `notification.date` is in seconds on iOS and milliseconds on Android, so always read it through `notificationDate`.
- **Photos:** `Medication.photoFile` stores a file name, not a path, because the iOS app container path can change. Resolve it with `photoUri` from `src/lib/photos.ts`.
- **Theming:** `src/constants/theme.ts` is the single high-contrast light theme and holds the minimum font and button sizes.
- **Platforms:** iOS and Android only; web is not a target.
- **Imports:** `@/*` maps to `src/*`, and `@/assets/*` maps to `assets/*`.
