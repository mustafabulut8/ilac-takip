# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Graduation project: an AI-assisted medication tracking and family notification system for elderly users, built with React Native (Expo SDK 58, TypeScript), Supabase, and Expo Notifications. `README.md` is written in Turkish and lists the planned features.

Only the skeleton exists. `app/` still shows the Expo starter screens, `docs/` and `supabase/` are empty, and neither Supabase nor `expo-notifications` is installed yet.

## Commands

The repo has no root `package.json`, so run all of these from `app/`:

```bash
npx expo start              # dev server (i / a / w to open iOS, Android, web)
npx tsc --noEmit            # typecheck
npx expo install <package>  # add dependencies with SDK-compatible versions
npx expo-doctor             # diagnose dependency and config issues
```

- `expo-env.d.ts` is gitignored and generated by `expo start`. On a fresh clone, `tsc` reports missing CSS module types until the dev server has run once.
- No test runner is set up.
- ESLint is not installed yet. The first `npx expo lint` adds it and its config to the project, so expect `package.json` changes.
- Do not run `npm run reset-project` casually: it moves or deletes `src/` and `scripts/`.

`app/AGENTS.md` holds the Expo rules: check versioned docs rather than relying on memory, and never hand-edit generated `ios/` or `android/` folders.

## Architecture

- **Routing:** Expo Router with its root at `app/src/app/` (not `app/app/`). Typed routes and the React Compiler are enabled in `app.json`.
- **Tabs are defined per platform:** the root layout renders `AppTabs`, which resolves to `app-tabs.tsx` (`NativeTabs`) on native and `app-tabs.web.tsx` (`expo-router/ui` headless tabs) on web. Adding or removing a tab means updating both files.
- **Platform files:** `.web.ts(x)` variants also exist for `animated-icon` and `use-color-scheme`. Check for a sibling before changing either one.
- **Theming:** colors, spacing, and fonts live in `src/constants/theme.ts`, which also imports `src/global.css` (web font variables). Components read colors through `useTheme` or the `ThemedText` and `ThemedView` components.
- **Web rendering:** `web.output` is `server`, so web pages render on the server first. This is why `use-color-scheme.web.ts` returns `light` until hydration.
- **Imports:** `@/*` maps to `src/*`, and `@/assets/*` maps to `assets/*`.
